# Apps Script API (사용 중단)

이 폴더는 Supabase 전환 전 백엔드의 이력 보존용입니다. 운영 웹앱 배포는 2026-08-07 보안상 중지했습니다.

이 백엔드는 액세스 코드 하나로 시트 전체(이름·전화번호 포함)를 열어주고 시도 횟수 제한도 없습니다.
그래서 실수로 다시 배포되더라도 데이터가 나가지 않도록 두 겹으로 막아 두었습니다.

- `Code.gs` 맨 위의 `var DISABLED = true` — `doGet`/`doPost`가 즉시 거부합니다.
- `appsscript.json` 의 `"access": "MYSELF"` — 익명 공개로 배포되지 않습니다.

> 이 두 값을 되돌리거나 `VITE_API_URL`을 운영 환경에 설정하지 마세요.
> 현재 운영 백엔드는 `supabase/`의 마이그레이션과 Supabase Auth를 사용하며,
> 프론트엔드에는 Apps Script 호출 경로가 아예 남아 있지 않습니다.

## 남은 확인 사항

코드를 막는 것과 배포가 실제로 내려간 것은 다릅니다.
Apps Script 편집기에서 **배포 → 배포 관리**를 열어 기존 배포가 모두 **보관(archive)** 상태인지 직접 확인하세요.

## API 요약

프론트엔드는 이 URL로 `POST` (본문 = JSON 문자열, `Content-Type: text/plain`) 를 보냅니다.

| action | 설명 | 권한 |
|--------|------|------|
| `login` | 액세스 코드 검증 | - |
| `getMembers` | 명단 조회 (순장=자기 순 / 최고권한=전체 또는 지정 순) | 로그인 |
| `getAttendance` | 특정 날짜 출석 조회 | 로그인 |
| `getAttendanceRange` | 권한 범위의 출석 이력 조회 | 로그인 |
| `saveAttendance` | 출석 일괄 저장 | 로그인 |
| `addMember` | 신규자 등록 (초신자→새순 / 진급자→새내기순) | 로그인 |
| `assignGroup` | 신규자를 일반 순에 배정 | 최고권한 |
| `renewMembers` | 여러 순원의 현재 소속을 일괄 재배정 (과거 출석 이력 보존) | 최고권한 |
| `syncMemberGroupNames` | `members.순이름`을 `groups` 기준으로 생성·동기화 | 최고권한 |
| `getLeaders` | 순별 순장과 개별 로그인 코드 조회 | 최고권한 |
| `setLeader` | 순장 지정·추가 및 로그인 코드 자동 발급 | 최고권한 |
| `clearLeader` | 선택한 순장 해제 및 로그인 계정 비활성화 | 최고권한 |
| `regenerateCode` | 선택한 순장의 로그인 코드 재발급 | 최고권한 |

## 정기 순 리뉴얼

1. 최고권한으로 앱의 **리뉴얼 → 1. 순원 재배정**을 엽니다.
2. 현재 순별로 새 소속을 선택하고 변경 대기 인원을 확인한 뒤 한 번에 저장합니다.
3. **2. 순장 재지정**에서 일반 순의 새 순장을 지정하고, 새순·새내기순은 필요한 수만큼 추가·해제합니다.
4. 일반 순장이 바뀌면 이전 로그인 코드는 자동 폐기되고 새 코드가 발급됩니다.

순원 재배정은 `members`의 `순ID`, `순이름`, `순배정일`만 갱신합니다. `attendance`의 기존 행은 당시 순 정보 그대로 유지되므로 과거 통계가 깨지지 않습니다. 기존 `members` 탭에 `순이름` 열이 없어도 리뉴얼 화면을 처음 열 때 자동으로 생성되고 `groups.순이름` 기준으로 채워집니다.

## 새 순·새내기순의 다중 순장

- 일반 순은 기존처럼 순장 1명만 지정됩니다.
- `유형`이 `새순` 또는 `새내기`인 순은 인원 제한 없이 여러 순장을 지정할 수 있습니다.
- 특별 순의 `groups.순장_member_id`에는 member ID가 `12, 34, 56`처럼 쉼표로 저장됩니다.
- `users`에는 순장마다 별도 행과 액세스 코드가 생성되므로, 코드 재발급과 해제도 개인별로 처리됩니다.

## 코드 관리(선택)

로컬에서 Git으로 관리하려면 [clasp](https://github.com/google/clasp) 사용:

```bash
npm i -g @google/clasp
clasp login
clasp clone <스크립트ID>
```
